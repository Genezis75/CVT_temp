# CVT TEMP — Suzuki Hustler (Android APK)

Нативное Android-приложение для вашего **классического Bluetooth ELM327 v1.5**
(тот, что работает с SZ Viewer). Не требует BLE.

## Что внутри
- Два одинаковых линейных индикатора с пиктограммами: **вариатор** и **двигатель**.
- График обеих температур сразу после блока температур.
- Крупные цифры, пороги «горячо»/«перегрев», звук + вибрация.
- **Виджет на рабочий стол Android** (две температуры, шкалы, зоны).
- Статистика сессии, экспорт CSV в папку Download.
- Настройка OBD-источников: CVT `7E1 · 2104 · A−50`, ДВС `7E0 · 0105 · A−40`.
- Демо-режим для проверки интерфейса без адаптера.

## Сборка APK через GitHub (без Android SDK на вашем ПК)
1. Создайте пустой репозиторий на GitHub.
2. Загрузите в него **содержимое** этой папки (чтобы `.github` и `app` были в корне).
3. Откройте вкладку **Actions** → запустится workflow **Build APK**.
4. Когда сборка завершится (зелёная галочка), скачайте артефакт **CVT-TEMP-APK**.
5. Внутри архива — `app-debug.apk`. Перенесите на телефон и установите
   (разрешив установку из неизвестных источников).

## Сборка в Android Studio
Откройте папку проекта → дождитесь синхронизации Gradle →
**Build → Build Bundle(s)/APK(s) → Build APK(s)**.

## Первое подключение
1. Сопрягите ELM327 с телефоном в настройках Android (PIN обычно 1234 или 0000).
2. Вставьте адаптер в OBD2, включите зажигание.
3. В приложении нажмите **Подключить адаптер** → выберите ваш ELM327 в списке.
4. При появлении разрешения Bluetooth — разрешите.
5. Если CVT показывает «NO DATA» — нажмите **Поиск** или выберите протокол **Авто**.

## Виджет
Долгое нажатие на пустом месте рабочего стола → **Виджеты** →
**CVT TEMP** → перетащить на экран. Данные приходят, пока приложение работает
(в фоне оно продолжает опрашивать адаптер, пока активно соединение).

## Разрешения
- Bluetooth (подключение к сопряжённому адаптеру) — обязательно.
- Вибрация — для тревоги перегрева.
- Память — только для экспорта CSV (на Android 9 и старше).
